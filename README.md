# My Shifts — app downloads

This repository only hosts the installable Android app **My Shifts**. The source code is private and is not published here.

## Install or update

1. On your phone, open the **newest release**: https://github.com/Ara-brrr/My-Shift-Public/releases/latest
2. Download **MyShifts.apk** and open it. If Android asks, allow your browser to install unknown apps.
3. Updates install over the old version and keep your calendar link and settings.

From version 7.0 the app checks this repository itself and offers new versions inside the app (menu → About). Automatic installation can be switched on in the menu.

## Verify a download

Every release shows GitHub's SHA-256 digest for `MyShifts.apk`; `latest.json` in the same release carries the same value, and the app checks it before installing. Android additionally refuses any update that is not signed with the app's own key.

## Privacy

The app ships without any calendar address — you paste your own webcal link once, and it stays on your phone.
